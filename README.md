# 🛒 Desconto Progressivo

Este projeto é um programa desenvolvido em **Python** que calcula descontos progressivos de acordo com o valor total de uma compra.

## 📌 Objetivo

O programa solicita ao usuário o valor total da compra e aplica automaticamente o desconto correspondente:

* 🟢 **Menor que R$ 200,00:** 5% de desconto
* 🟡 **De R$ 200,00 até menos de R$ 300,00:** 10% de desconto
* 🔵 **R$ 300,00 ou mais:** 15% de desconto

Após calcular o desconto, o programa informa o valor do desconto e o total a ser pago.

## 💻 Tecnologias utilizadas

* 🐍 **Python**
* 🐙 **Git**
* 🐙 **GitHub**

## ▶️ Como executar

1. Tenha o **Python** instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo `app.py`.
5. Digite o valor total da compra quando solicitado.

## 🧮 Cálculo

```text
Valor do desconto = valor da compra × percentual de desconto

Total a pagar = valor da compra - valor do desconto
```
